# AI-RL-Repo
A collection of hands-on learning examples, Python implementations, Google Colab notebooks, and practical experiments exploring Artificial Intelligence (AI), Machine Learning (ML), and Deep Reinforcement Learning (DRL).

## Repository Contents

This repository currently contains the following projects and utilities:

### 1. Lunar Lander agent – Reinforcement Learning
**File:** `Lunar_lander_agent.ipynb`

### 2. Huggy the Dog – Reinforcement Learning
**Folder:** `02_Huggy_Dog`

A Google Colab notebook demonstrating the training of a Reinforcement Learning agent using the Lunar Lander and Huggy the Dog environment.

### 3. Download Trained Model
**File:** `Download_trained_model.py`

A Python utility script for downloading previously trained models to a local device or computer, allowing them to be stored and accessed outside the Google Colab environment.
Note : Mention the name of the zip file model you want to download.
